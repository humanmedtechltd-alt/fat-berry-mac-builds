# Fat Berry Mac build controller

Public build scripts for Fat Berry DSP. Product sources, dependency snapshots, compiler logs and customer release artifacts remain private.

Only standard GitHub-hosted runners are used. This repository does not enable paid runners or change account spending limits.

The preflight builds and executes a tiny universal Mach-O executable, tests ad-hoc signing, and constructs an unsigned installer package and disk image. It contains no product code or credentials.
